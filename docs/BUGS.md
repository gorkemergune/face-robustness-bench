# Bugs and fixes

| #   | Bug                                   | Symptom                                         | Fix                                                                                 | Status | Test |
| --- | ------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------------------- | ------ | ---- |
| B1  | EXIF rotation ignored                 | Phone photos not detected                       | `load_image_bgr` applies `ImageOps.exif_transpose` before detection                 | Prevented | `test_b1_exif_rotation_is_applied` |
| B2  | BGR/RGB mix-up                        | Low genuine scores                              | Loader converts RGB -> BGR (what InsightFace expects); checked against `cv2.imread` | Prevented | `test_b2_loader_returns_bgr` |
| B3  | Heavy filters cause no detection      | Missing rows                                    | Every image yields a row; failures have `detected=False`, `recognized=False`, are counted in `detection_fails` | Prevented | `test_t14_detection_failure_counted`, `test_unreadable_probe_is_failure_not_crash` |
| B4  | Centroid not re-normalized            | Scores shifted                                  | Embeddings normalized before averaging, centroid normalized after                  | Prevented | `test_t8_centroid_normalized`, `test_b4_centroid_not_dominated_by_large_norm` |
| B5  | Too few impostors                     | Unstable tau                                    | Warn, record coarser `far_effective = 1/n`, put tau above the highest impostor; also use other enrolled persons as impostors by default | Prevented | `test_b5_too_few_impostors_falls_back` |
| B6  | Gallery photos leak into probes       | Inflated clean score                            | SHA-256 de-dup before split; probes identical to any clean photo are excluded with a warning; impostor pairs skip the person's own clean hashes | Prevented | `test_b6_duplicates_removed_before_split`, `test_b6_probe_identical_to_clean_excluded` |
| B7  | Non-determinism across runs           | Different tau                                   | Sorted listings, `random.Random(42)` split, deterministic embeddings cache         | Prevented | `test_t6_split_deterministic`, `test_b7_deterministic` |
| B8  | B5 fallback used the coarse FAR to pick tau | With 20 impostors at FAR=1%, one impostor (5%) was still accepted, contradicting the "tau above max impostor" warning | `calibrate` always calls `tau_at_far` with the requested FAR (k = 0 -> tau above max); `far_effective` only records the resolution | Fixed | `test_b5_too_few_impostors_falls_back` |
| B9  | Tightly cropped selfies not detected  | SCRFD misses faces that fill the whole frame    | Retry detection on a 30% zero-padded image when the first pass finds nothing       | Prevented | `test_t2_no_face_returns_none_after_pad_retry`, `test_pad_retry_detects_tight_crop` |
| B10 | `insightface` 2.1 `det_size` defaults to `None` | Unpredictable detector input size       | Always pass `det_size=(640, 640)` to `FaceAnalysis.prepare`                         | Prevented | - |
| B11 | Noisy `FutureWarning` per face from scikit-image (`tform.estimate`) | Log spam during runs | Filtered in `embedder.py` for the `insightface` module only                         | Fixed | - |
| B12 | `--results-md ''` did not disable the results document | `IsADirectoryError: '.'` because `Path('')` is `Path('.')`, which is truthy | Parse `--results-md` as `str` and convert only when non-empty | Fixed | `test_cli_runs_both_backends` |
| B13 | `python -m frbench.cli` -> `ModuleNotFoundError: frbench` after an editable install | macOS keeps setting the `hidden` flag on files inside `.venv` (project lives on the synced Desktop); Python 3.13 skips hidden `.pth` files, so the editable install silently stops working | Install non-editable (`pip install .`, re-run after code changes); pytest uses `pythonpath = ["src"]` and is unaffected | Fixed (workaround) | - |
| B14 | Qwen-VL: a confident "different" scored higher than an unsure "same" | Raw `confidence` is certainty in the answer, not similarity | Score each answer as P(same) = conf/100 if same else 1 - conf/100; keep raw mean confidence as a separate column | Superseded by B18 | `test_p_same_mapping` |
| B15 | Qwen-VL: refusals / chatter instead of JSON | Would crash `json.loads` or drop rows | `parse_answer` classifies `refusal` vs `invalid_json`; probe becomes a failure row when fewer than `min_valid` (2) of 3 answers are valid; counted per kind in the report | Prevented | `test_parse_failures`, `test_refusal_and_invalid_are_failure_rows` |
| B16 | Qwen-VL: Ollama down or model not pulled | Hours of ArcFace work, then every VLM query fails | `preflight()` checks `/api/tags` before any backend runs; CLI prints a clean error (exit 2). Transport errors mid-run are `backend_error` rows and are not cached, so a re-run retries them | Prevented | `test_preflight_fails_fast`, `test_transport_error_is_failure_and_not_cached`, `test_cli_reports_ollama_down` |
| B17 | Qwen-VL: stale cache after changing model/prompt | Old answers reused for a new configuration | Cache key = hash(model, prompt, options, format, max_side) + reference SHA-256 + probe SHA-256 | Prevented | `test_cache_invalidated_by_model_change` |
| B18 | Qwen-VL on real data: `{"same": false, "confidence": 0}` for a stranger | qwen2.5vl reports confidence as *match probability*, so the B14 formula gave the stranger P(same) = 1.0 (top score) | "different" answers now map to min(c, 100 - c)/100, which is right under both readings and never above 0.5 | Fixed (found in the first real query, before the full run) | `test_p_same_mapping` |
| B19 | ArcFace real run took 3h42m for ~1060 images | Only 11% CPU: the Mac went to sleep during the run | Long runs are started under `caffeinate -i` | Fixed | - |

## Environment notes

- Python 3.11 was not installed on the dev machine; the venv uses Python 3.13 (all tests pass). `requires-python >= 3.11`.
- `buffalo_l` recognition model is `w600k_r50.onnx` (ArcFace ResNet-50 trained on WebFace600K), not R100 as stated in PLAN.md.
