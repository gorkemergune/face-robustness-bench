# Project rules
- Language: all code, comments, docs, commit-free notes in English.
- NEVER run git commit, git push, or git add. Local file edits only.
- Never open, print or upload files under data/. Only process them via code.
- Python 3.11+ (3.13 venv used locally), src/ layout, type hints, small functions.
- Run `pytest -q` after every change; fix failures before continuing.
- Keep outputs reproducible: fixed random seeds, deterministic splits.
- Log every bug and fix in docs/BUGS.md.
